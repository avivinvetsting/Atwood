# Atwood Machine Lab — מעבדת מכונת אטווד

סימולציה פיזיקלית אינטראקטיבית ומדויקת של מכונת אטווד, המיועדת להוראה, למידה והדגמות מתקדמות בפיזיקה (כולל הכנה לבגרות).

היישום מאפשר חקירה מעמיקה של תנועת גופים מחוברים, חוקי ניוטון, מתקף, מצבי חוט רפוי ומתוח, והתנגשויות עם הקרקע.

---

## 🚀 תכונות עיקריות

* **מודל פיזיקלי אנליטי מלא ומדויק:**
  * תנועה משותפת מואצת ושיווי משקל סטטי / דינמי.
  * זיהוי מדויק של רגעי פגיעה בקרקע, עצירה וכוח נורמלי ($N_1, N_2$).
  * טיפול בחוט רפוי ($T=0$) ותנועת זריקה אנכית חופשית של הגוף המשוחרר.
  * חישוב מתקף ואיבוד אנרגיה במתיחת חוט מחדש לאחר מצב רפוי.
  * תמיכה במהירות התחלתית בכל כיוון, כולל שיגור גוף הנמצא על הקרקע.

* **הדמיה ויזואלית עשירה ואינטואיטיבית:**
  * הדמיית גלגלת, חוט (כולל מראה רפוי מול מתוח) ומשקולות.
  * סרגל גובה במטרים וקרקע.
  * תרשים כוחות חופשיים (FBD) חי עם חיצים ותוויות גדלי כוח בזמן אמת.
  * עיצוב בהיר ונקי (Light theme) בעברית, מותאם לכיתה, מקרן ומסכי מגע/מחשב.

* **מערכת גרפים מתקדמת:**
  * גרפי מקום-זמן $y(t)$, מהירות-זמן $v(t)$, וכוחות $T(t), N(t)$.
  * צירים קבועים המחושבים מראש לפי תחזית אנליטית (ללא שינויי קנה מידה תוך כדי תנועה).
  * כפתור **"הגדלה" (⛶)** לצפייה בגרפים על פני חלון מלא תוך המשך עדכון חי.
  * כפתורי הצגה/הסתרה (Toggle) לכל כוח ($T, N_1, N_2$) בנפרד.

* **צפייה חוזרת (Replay Scrubbing):**
  * סליידר זמן במצב השהיה המאפשר גרירה לאחור וסנכרון מלא של המכונה, הטבלה, הגרפים והסטטוס.

* **ייצוא נתונים מלא:**
  * ייצוא היסטוריית המדידות לקובץ CSV (כולל $t=0$, תאוצות, נורמלים ודגימות אירועי פגיעה/מתקף).

* **קובץ עצמאי (Offline Standalone):**
  * הקובץ `atwood-lab.html` כולל את כל ה-HTML, ה-CSS וה-JavaScript במקום אחד, ועובד באופן מלא בכל דפדפן ללא צורך בשרת או בחיבור לרשת.

## 📂 מבנה הפרויקט

```
Atwood/
├── atwood-lab.html          # יישום עצמאי יחיד (Offline, מוכן לשיתוף ופתיחה ישירה)
├── index.html               # קובץ HTML מקור
├── style.css                # עיצוב וסגנון
├── app.js                   # ניהול הממשק והאירועים
├── physics.js               # מנוע הפיזיקה והחישוב האנליטי
├── planning.js              # חיזוי תנועה וחישוב צירים וגאומטריה מראש
├── renderer.js              # ציור המכונה, הכוחות והקנבס
├── charts.js                # ציור וניהול הגרפים
├── tools/
│   └── build_standalone.js  # סקריפט הידור של קובצי המקור ל-atwood-lab.html
├── tests/                   # חבילת בדיקות יחידה, פיזיקה ודפדפן
├── verification/            # תוצאות אימות, צילומי מסך ודוחות
└── wiki/                    # תיעוד ארכיטקטורה ומודל פיזיקלי
```

## 🛠️ הפעלה ובדיקות

### הרצה ישירה:
פשוט פתחו את `atwood-lab.html` או את `index.html` בדפדפן מודרני (Chrome, Edge, Firefox, Safari).

### בניית הקובץ העצמאי (לאחר שינויי מקור):
```bash
node tools/build_standalone.js
```

### הרצת חבילת הבדיקות (Node.js):
```bash
# בדיקות מודל פיזיקלי
node tests/physics_test.js

# בדיקות תחזית וצירים
node tests/planning_test.js

# בדיקות רגרסיה מתמטיות
node tests/regression_test.js

# בדיקות קנבס ורינדור
node tests/ui_render_test.js

# בדיקות אינטגרציה בדפדפן (דורש Playwright)
node tests/browser_test.js
node tests/fixed_axes_browser_test.js
node tests/live_layout_test.js
node tests/replay_browser_test.js
node tests/graph_controls_browser_test.js
```
